# Rapid Cycle

## Ideal State

In a time-boxed setting, return a small but genuinely evolved portfolio rather than a familiar list. The result preserves lineage, labels imagination separately from evidence, and identifies the one reality check that should govern a longer run.

## Compact Cycle

Run a compressed population through **CONSUME → DREAM → DAYDREAM → SALON → STEAL → MATE/MUTATE → TEST → SELECT**. Use at least two unrelated disciplinary lenses, one deliberately imperfect mechanism transfer, and multiple parent lineages. Treat the output as cycle 1, not as proof.

Use BeCreative inside CONSUME, DREAM, DAYDREAM, or SALON only for fast divergent expansion; then apply Novelty’s lineage, testing, and selection contract.

## Output Contract

Return:

- **Reality frame:** problem, hard constraints, and the one decisive test.
- **Three or more candidates:** different niches, each with lineage, mutation/transfer, fantasy-or-evidence label, and test status.
- **Selected portfolio:** a leading candidate, a contrarian wildcard, and an explanation of the diversity retained.
- **Next evolution rule:** what to amplify, suppress, or test in cycle 2.

## Guardrails

Do not compress away DREAM, deliberate misapplication, reality testing, or diversity selection. If the time budget cannot support these, recommend BeCreative for a single-pass brainstorm instead of claiming an evolutionary run.
